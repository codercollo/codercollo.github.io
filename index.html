Projects

  • Simple Bank

    A backend banking API focused on account management, transfers, and transactions. The core challenge here is concurrency — ensuring that concurrent transfers don't corrupt account balances, using database transactions and careful lock ordering.

    Go · PostgreSQL · SQLC · JWT · Docker

  • GoTP

    An OTP service that sends and verifies SMS codes while helping prevent fraudulent SMS requests. Addresses the engineering problem of idempotency and rate-limiting: how do you ensure an OTP is used exactly once, and that the system can't be abused to send arbitrary SMS traffic?

    Go · SMS Gateway · Security · Rate Limiting

  • RentLoop

    A WhatsApp bot that automates rent collection — reminders, payment tracking, and tenant communication. Practical exercise in integrating with an external messaging API and handling asynchronous message flows reliably.

    Go · WhatsApp API · Webhooks · Automation

  • URL Shortener

    A simple URL shortening service. Clean API design, fast redirects, and an exercise in thinking about ID generation, collision avoidance, and keeping a service small and purposeful.

    Go · REST · PostgreSQL

About

I'm Collins Kimani, a backend developer working primarily with Go. I'm based in Nairobi, Kenya. You can find my code on GitHub under @codercollo.

My interest is in understanding how software systems work beneath the surface — not just writing code that runs, but understanding why it behaves the way it does, where it can fail, and how to build things that hold up under real conditions.

I'm particularly interested in:

  • Building practical backend applications with Go
  • Understanding system behaviour and engineering trade-offs
  • Learning through implementation rather than theory alone
  • Documenting engineering concepts as I encounter them
  • Continuously improving my software design and problem-solving skills

The projects on this site — Simple Bank, GoTP, RentLoop, and the URL Shortener — are practical exercises in applying what I study. Each one involved an engineering problem worth thinking carefully about: concurrent transactions, idempotent operations, external API integration, or clean API design.

The Engineering Notes section is where I write down what I learn. Writing is how I check whether I actually understand something. If I can explain a concept clearly, I probably understand it. If the explanation gets muddy, I probably have more studying to do.

I'm not looking to collect technologies. I'd rather understand fewer things well than have a long list of tools I've touched briefly.
